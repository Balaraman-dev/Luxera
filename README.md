✨ LUXERA — Modern E-Commerce Shopping Platform

Luxera is a sleek, interactive, and beautifully crafted E-Commerce Web Application, built in November 2024.
This project blends technology, UI/UX collaboration, and dynamic product loading to deliver a premium shopping experience.

🛒 About Luxera

Luxera showcases 190+ real-time products using clean UI patterns, a responsive layout system, and seamless interactions.
The platform is designed to feel premium, smooth, and user-friendly, making browsing effortless across all devices.

🛠 Installation & Setup Guide

Follow these steps to run Luxera on your local system.

1️⃣ Clone the Repository
git clone https://github.com/Balaraman-dev/Luxera.git

2️⃣ Navigate into the Directory
cd Luxera

3️⃣ Install Dependencies

Make sure Node.js and npm are installed.

npm install

4️⃣ Start the Development Server
npm run dev


Vite will display a local URL like:

http://localhost:5173/


Open it in your browser to explore Luxera locally.
